# 四部冒险及关联谜题：结构化提示覆盖状态

本报告对应 `src/hints/coverage.js`（程序中的覆盖状态来源）。目前包含四张主地图与 **42 道关联／首领题**，共 46 项。

## 状态定义

- **certified（14 道）**：原版 SCL 经过指纹绑定，并对作者声明的全部数字规则完成结构化录入、答案离线一致性校验；求解器按照明确类型推理，不从颜色猜测。
- **partial（32 项，包括四张主地图）**：已支持部分可靠数字约束，但仍有尚未建模的数字、区域、路径或互动状态；游戏内提示面板会显示未覆盖的机制，不会宣称谜题已完整支持。

完整规则建模与**保证存在可读的下一步**是不同概念：即使约束全部录入，某个中间盘面可能超出目前等级 1–4 的人类推理技巧。中心／角标手记仅用于避开已做过的排除，不能被当作数字已确定的证明。

## 此次扩展的通用推理

奇数／偶数标记、方向性不等号、等位克隆、行内列索引、X-Sums、小杀手对角线求和、固定配料三明治、摩天楼可见数量、未知圆头方向温度计、较长的箭头／Killer 求和、最多九格的连续数线。

多格和使用精确动态规划排除**所有合法组合都不可能**的候选数；不会因为搜索预算用尽而猜测。九格连续线用二分匹配查找完整支持；摩天楼回溯有明确上限，超过预算则跳过这条推理。由于需要同时满足数独的其余不重复关系，忽略附加关系的局部总和枚举只会造成**漏排除**，不会造成假排除。

## 尚需独立求解状态的类型

不能仅凭格子当前大数字和 SCL 绘制内容完整实现以下类型：

- **路径与连通**：蛇与双蛇、Cave/Akari、Icelom、星系旋转对称、皇后／主教视线与避让、闪现最近目标、不可自接触的跨宫等和路径。
- **动态区域**：待推导不规则宫、重新排列和旋转照片里的宫、实时由玩家解锁／绘制的边界。
- **变动数值**：Copycat 转置值、高温格数值 +1、冰柱修正值、十和线交叉处分摊、可变三明治配料。
- **画线动作与变形**：墙边反弹导弹、随玩家确定的线条变体与剧情中的交互状态。

对尚未确定的动态不规则宫，求解器不能把 SCL 中**答案使用的实际宫划分**当成玩家已经知道的约束；本迭代已增加这一防偷看处理。

## 验证原则与后续完成标准

1. 源文件、指纹、区域坐标、线条路径、题面规则类型和离线解答一致。
2. 用真实题目在初始、中途、局部迷雾、错误玩家候选记号等状态测试，逐条排除任何错误结论。
3. 动态路径类需要结构化**玩家绘制状态**，以及搜索器能提供可读的局部证据格和文字。
4. 只有一道题全部规则有模型、独立验证与回归测试后，才允许从 partial 升为 certified。
5. 46 项全部 certified，且 Android 与 Web 真实盘面提示、前端测试和 WASM/Rust CI 全部通过，才可称为“四部冒险及关联谜题的所有变体全面支持”。

请不要根据已有局部提示把 partial 状态标为 certified。
