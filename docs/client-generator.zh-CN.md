# 本机数独生成器（Rust / WASM）

SudokuPadX 的「本机数独创作」位于**首页**，也可从**谜题库 → 我的本机生成谜题**进入。无须联网、无需 Python、不会覆盖内置题目。

## 使用

1. 选择 4×4、6×6 或 9×9。当前第 3–5 级只适用于 9×9。
2. 选择 **技巧等级** 1–5，并可指定一个必须在真实推理过程中发挥作用的重点技巧。指定后，生成器还会禁用该技巧再次求解：若题目仍能解完，则不接受。
3. 勾选一或多种变体规则，包括杀手笼、黑白点、温度计、连续线、箭头、V/X、耳语线、熵线、模三线、夹心线和区域和线；全部取消则生成经典数独。不同棋盘大小仅提供引擎支持的规则。
4. 选择规则密度、随机种子和最大尝试次数。高阶技巧需要较少规则与特定逻辑结构，**并不是任意配置都能生成成功**。找不到符合条件的题目时会明确失败，不把易题谎称高阶题。
5. 生成成功后先写入本机 IndexedDB，再进入 SudokuPadX 的同一个 Rust 解题引擎。可继续解题、**收藏**、**标记完成**或**删除**；个人谜题也会出现在普通谜题库筛选中。

## 等级语义

| 等级 | 当前本机 Rust 课程逻辑 | 验证方式 |
| --- | --- | --- |
| 1 | 同行同列同宫排除、隐性唯一数、变体局部关系 | 纯推理完成 |
| 2 | 显性／隐性数对数组、锁定候选数 | 等级 1 无法完成，等级 2 能纯推理完成 |
| 3 | X-Wing、Swordfish、XY-Wing、Skyscraper | 等级 2 无法完成，等级 3 能纯推理完成，实际发生对应等级的候选排除 |
| 4 | Jellyfish、XYZ-Wing、XY-Chain（及所有低等级技巧） | 等级 3 无法完成，等级 4 能纯推理完成，实际发生对应等级的候选排除 |
| 5 | 不声称有纯逻辑证明 | 等级 4 求解器无法解完，**独立精确搜索证明只有一个答案**；可能需要试探、回溯或本机课程尚未实现的高级逻辑 |

**重要区别：**这里的「第 5 级」**不代表已证明人类必须猜测**，更不代表题目无解。它仅表示当前客户端第 4 级求解器无法完成、精确解数仍为 1。建议不喜欢试错的玩家选 1–4。

此前 Python 预生成题库包含额外的 Killer Innies/Outies、更多混合结构和更长的链。本机 Rust 课程是明确公布的**独立技巧子集**，并非逐项等价于 Python 教材所有技巧。不能据此把未实现的技巧默认为「穷举」。

## 数据、安全与性能

- 核心在 \`crates/sudokupadx-core/src/creator.rs\`，Android 通过 \`spawn_blocking\` 在工作线程调用。网页通过独立 Web Worker 初始化同一份 Rust → WebAssembly 内核，不阻塞棋盘渲染。
- 每题先使用随机数种子构造合法完整数独；从答案中提取真实变体几何，再删除可省略提示。**逻辑求解和精确数解不允许读取已生成的答案**，答案仅用于最终验证、填充元数据和玩家的错误检查。
- 只接受符合指定逻辑等级的谜题。独立回溯计数必须返回恰好一个解；如果勾选了变体，去掉全部变体时还必须有两个以上解，证明至少有额外规则真正影响题目。
- 浏览器与 APK 采用相同格式、渲染与已支持的存档引擎。所有生成题目的完整内容、标题、星标与完成标记保存在设备的 \`sudokupadx-personal-v1\` IndexedDB 中。数字与笔记继续用原有进度系统保存。
- 删除将同时删除本机生成题面、对应进度和当前恢复缓存。清除浏览器站点数据或卸载 App 后本机题面无法自动恢复；它们**不会**上传云端。
- 生成器有尝试次数、约束枚举与精确解数搜索上限，防止不受限制地耗尽移动设备资源。高阶题失败是合理结果，调整设置即可重试。

## 验证

\`\`\`sh
cargo test -p sudokupadx-core --all-targets
npm test
npm run build:web
\`\`\`

浏览器 WASM 冒烟测试应覆盖在没有网络请求时创建独立谜题、打开、重载后保留、收藏／标记以及删除。
